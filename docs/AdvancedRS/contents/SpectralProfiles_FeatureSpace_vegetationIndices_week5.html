This week

Guiding question: How can we use spectral signatures, two-band feature spaces and vegetation indices to distinguish land-cover types and interpret vegetation characteristics in our own Sentinel-2 image?

Last week you prepared a cloud-masked Sentinel-2 multiband GeoTIFF. This week you will work with your own image to digitize reference areas in QGIS, extract their spectral signatures in R (terra), explore feature spaces and calculate three vegetation indices: NDVI, EVI and PVI. Finally, you will create a simple NDVI map in QGIS.

If you did not yet finish your pre-procssing or did have problems that are not solved yet, use the backup GeoTIFF (https://box.fu-berlin.de/s/DtyPf28bSjZDsg9). Use the same image throughout all exercises and document which image you used.

Learning objectives

After this session you should be able to:

  • identify and digitize homogeneous land-cover samples in QGIS and save them as a GeoPackage;
  • extract and interpret mean spectral reflectance profiles using Sentinel-2 bands;
  • explain a spectral feature space and compare the separability of land-cover types;
  • calculate and interpret NDVI, EVI and PVI, including the role of the soil line;
  • create and interpret a simple vegetation-index map.

Continue the remaining analyses and homework during the week. It is not necessary to complete every section during the seminar itself.

ImportantReflectance scaling matters

Sentinel-2 images store reflectance information as scaled digital numbers (DNs). Before calculating vegetation indices such as NDVI and EVI, we convert these values to surface reflectance:

\[ \rho = \frac{DN + BOA\_ADD\_OFFSET}{BOA\_QUANTIFICATION\_VALUE} \]

The required values are provided in the Sentinel-2 metadata (MTD_MSIL2A.xml in the SAFE folder). Look for BOA_QUANTIFICATION_VALUE and BOA_ADD_OFFSET. Note that the XML band_id numbering differs from Sentinel-2 band names (e.g., band_id="1" refers to B02 as they are starting to count from 0).

The scaling factor is usually 10,000, while the offset depends on the processing baseline (typically −1,000 for baseline/version 04.00 and later). Always check your product’s metadata.

Show code
## Choose based on your inspected GeoTIFF:
scale_factor <- 10000  # <-- CHECK and adjust for your processed image
offset <- -1000 # <-- CHECK and adjust for your processed image
image <- image_raw / scale_factor
# Important: this is correct only if your data are zero-offset scaled reflectance.
# If your original L2A product has an applicable additive offset that was
# not corrected in Week 4, apply the metadata-defined offset BEFORE scaling.

1.2 Make the band order explicit

Your Week 4 output should contain ten bands in the order B02, B03, B04, B05, B06, B07, B08, B8A, B11, B12. We use shorter names (B2 rather than B02) for the code below. If you used a different processing workflow, check the names and order carefully.

WarningDo not blindly rename bands

First inspect names(image). If your raster has exactly the ten Week 4 bands in the order shown, you may use the code below. Otherwise, adapt the selection and naming to your file. Do not confuse B8 (broad NIR) with B8A (narrow NIR).

Show code

## B02, B03, B04, B05, B06, B07, B08, B8A, B11, B12

                  "B8", "B8A", "B11", "B12")

plotRGB(image, r = match("B4", names(image)),
        g = match("B3", names(image)), b = match("B2", names(image)),

2. Create reference polygons in QGIS

You will identify a small selection of homogeneous land-cover areas and later inspect their reflectance in R. These polygons are reference samples for spectral exploration, not yet a statistically designed training/validation dataset.

Recommended classes (where available): forest, grassland, agricultural vegetation, bare soil / harvested fields, built-up surfaces and water. Aim for 10 to 15 small polygons covering at least four contrasting classes. If a class is absent in your study area, do not invent it.

TipAdditional guidance: Digitizing reference polygons in QGIS

For step-by-step instructions with illustrations, use our RESEDA – Sample in QGIS tutorial.

Note: The RESEDA example uses Landsat imagery and shapefiles. In this exercise, you will use Sentinel-2 imagery and a GeoPackage instead.

2.1 Display the Sentinel-2 image

  1. Open QGIS and save a new project (week05_reference.qgz).
  2. Choose Layer → Add Layer → Add Raster Layer, browse to your Sentinel-2 GeoTIFF and open it. You can also drag the file into QGIS.
  3. Right-click the raster → Properties → Symbology and choose Multiband color.
  4. Set Red = B4, Green = B3, Blue = B2. Use the raster’s actual band numbers/names. If necessary, adjust the min/max contrast stretch.
  5. Check the project CRS (bottom-right of QGIS) and the raster CRS (Layer Properties → Information). They should be geographically compatible; QGIS can reproject layers on the fly.

2.2 Add an optional high-resolution basemap

A basemap can help you recognize vegetation, buildings, water and fields. It must not replace your Sentinel-2 image as the main reference for spectral properties.

  1. In QGIS, open Plugins → Manage and Install Plugins.
  2. Search for QuickMapServices and install it (if permitted on your computer).
  3. Open Web → QuickMapServices and select an available basemap (e.g. an imagery basemap, if offered). Availability and licensing vary.
  4. In the Layers panel, place the basemap below your Sentinel-2 raster. Temporarily toggle the Sentinel-2 layer on/off or adjust its transparency to compare them.
  5. Important: Basemap imagery may be older or newer than your Sentinel-2 acquisition. If land cover differs, digitize what is visible in your Sentinel-2 scene.

You do not need QuickMapServices to complete the exercise. The provided RESEDA sampling guide also explains the workflow with imagery in QGIS.

2.3 Create a GeoPackage polygon layer

  1. Select Layer → Create Layer → New GeoPackage Layer.

  2. Save it as reference/landcover_samples.gpkg and set the table name to landcover.

  3. Choose Geometry type: Polygon.

  4. Set the layer CRS to the CRS of your Sentinel-2 raster, if possible.

  5. Add the following attribute fields:

    Field name Type Example
    class Text forest
    sample_id Whole number 1

  6. Click OK. The empty polygon layer should appear in the Layers panel.

2.4 Digitize your reference areas

  1. Select the landcover layer in the Layers panel.
  2. Click Toggle Editing (pencil icon).
  3. Click Add Polygon Feature.
  4. Left-click to place polygon vertices around a homogeneous area; right-click to finish the polygon.
  5. Enter its class, a unique sample_id, and optional notes in the attribute form.
  6. Repeat for your reference areas. Save edits regularly and toggle editing off when done.
  7. Open the attribute table and check that all polygons have valid class labels and unique IDs.
  8. Save the QGIS project.

Sampling tips

  • Prefer several small homogeneous polygons over a single very large polygon.
  • Avoid mixed pixels, borders of fields, coastlines, roads and deep shadows.
  • Allow for Sentinel-2’s pixel size: a polygon should contain several useful pixels, not just a tiny feature visible in the high-resolution basemap.
  • Sample different locations within a class where possible; different kinds of forest, grass and cropland are not spectrally identical.
  • If your scene has a large seasonal difference from the basemap, rely on the Sentinel-2 appearance and note any uncertainty.

Troubleshooting: If Add Polygon Feature is disabled, verify that the polygon layer (not the raster) is selected and editing is enabled. If your polygons appear in the wrong location, check the layer CRS and raster CRS; do not simply assign a different CRS to move geometries.

Useful additional reference: QGIS 3.44 documentation – Editing vector features.

4. Calculate mean spectral reflectance profiles

4.1 Extract reflectance for every polygon

Use terra::extract() to calculate the mean reflectance for all bands within each polygon. Areas covered by NA pixels (e.g. masked clouds) are ignored.

Show code
# Extract the mean reflectance of each spectral band for every polygon.
# Missing pixel values (NA), e.g. from cloud masking, are ignored.
ref <- terra::extract(image, landcover, fun = mean, na.rm = TRUE)

# Add the land cover class of each polygon to the extracted data.
# ref$ID identifies the corresponding polygon in 'landcover'.
ref$class <- landcover$class[ref$ID]

# Add the sample ID from the original polygons.
ref$sample_id <- landcover$sample_id[ref$ID]

# Display the first six rows of the resulting data frame.
head(ref)

Inspect: What does one row represent? Why do we use mean here? What might be the disadvantage of using a large or heterogeneous polygon?

4.2 Plot spectral profiles

Approximate central wavelengths (nm) for the ten selected Sentinel-2 MSI bands:

Band B2 B3 B4 B5 B6 B7 B8 B8A B11 B12
Wavelength (nm) 490 560 665 705 740 783 842 865 1610 2190

The wavelengths are rounded and may differ slightly by satellite (Sentinel-2A/B/C).

Show code
# Define the Sentinel-2 band names and their central wavelengths (in nm).
# The order must match the columns in the extracted reflectance data.
band_names <- c("B2", "B3", "B4", "B5", "B6", "B7",
                "B8", "B8A", "B11", "B12")
lambda <- c(490, 560, 665, 705, 740, 783, 842, 865, 1610, 2190)

# Select the reflectance values for all polygons and spectral bands.
# Convert the data frame into a matrix for plotting.
# Reflectance values range approximately from 0 to 1.
# Multiplying by 100 converts them into percentages.
spectra <- as.matrix(ref[, band_names]) * 100

# Identify the different land cover classes in the reference polygons.
classes <- unique(ref$class)

# Assign a different colour to each land cover class.
# Polygons belonging to the same class receive the same colour.
class_col <- setNames(grDevices::hcl.colors(length(classes), "Dark 3"), classes)

# Plot the spectral profile of each reference polygon.
# lambda defines the x-axis (wavelengths).
# t(spectra) transposes the matrix so that each polygon is plotted as a line.
# Line colours indicate the corresponding land cover classes.
matplot(lambda, t(spectra), type = "l", lty = 1, lwd = 1.5,
        col = class_col[ref$class], xlab = "Wavelength (nm)",
        ylab = "Surface reflectance (%)", main = "Sentinel-2 spectral profiles")

# Add a legend showing the land cover classes and their colours.
legend("topright", legend = classes, col = class_col[classes],
       lty = 1, lwd = 2, cex = 0.8, bty = "n")

Interpretation

  1. Where do healthy green vegetation spectra show strong absorption and high reflectance?
  2. Which bands help distinguish vegetation from soil and built-up surfaces?
  3. Are all polygons of the same class similar? Give a possible reason for differences.

5. Explore spectral feature spaces

Create a scatterplot (in remote sensing we name it feature space) between the red and the green band. Select four spectra ((a) water, (b) vegetation, (c) settlement, (d) soil -or alternatively, one of your other prepared land cover types) and plot them within the feature space. Similarly to the function lines() the function points() allows adding point data to a diagram. You may set the argument maxcell to increase the number of pixel data used for the feature space. If you set the number very high, creating the diagram may take a little while. In this example I used all spectra but as mentioned before, you may restrict yourself to four land cover types. A feature space plots the values of one spectral band against another. Each grey point represents an image pixel. Your coloured points represent mean reflectance of individual reference polygons.

6. Calculate vegetation indices

Vegetation indices combine spectral bands to emphasize specific characteristics of the surface. They are proxies, not direct measurements of vegetation amount or health. Different indices are sensitive to different conditions.

6.1 NDVI – Normalized Difference Vegetation Index

\[ NDVI = \frac{\rho_{\mathrm{NIR}} - \rho_{\mathrm{RED}}} {\rho_{\mathrm{NIR}} + \rho_{\mathrm{RED}}} \]

Show code
red <- image[["B4"]]
nir <- image[["B8"]]
blue <- image[["B2"]]

ndvi <- (nir - red) / (nir + red)
names(ndvi) <- "NDVI"
plot(ndvi, main = "NDVI")

6.2 EVI – Enhanced Vegetation Index

The EVI is calculated as following:

\[ EVI = G \cdot \frac{\rho_{\mathrm{NIR}} - \rho_{\mathrm{RED}}} {\rho_{\mathrm{NIR}} + C_1 \rho_{\mathrm{RED}} - C_2 \rho_{\mathrm{BLUE}} + L} \] where the parameters are G = 2.5, C1 = 6, C2 = 7.5 and L = 1 (after Huete et al. 2002).

6.3 PVI – Perpendicular Vegetation Index

Introduction

The perpendicular vegetation index (PVI) describes vegetation in a two-dimensional feature space defined by reflectance in the red and near-infrared spectral regions. The PVI is defined as the perpendicular distance of an observation from the soil line.

A line in two dimensions can be described by its slope \(a\) and intercept \(b\):

\[ y = ax + b \]

In our red–NIR feature space, the x-axis represents red reflectance and the y-axis represents NIR reflectance.

To define the soil line, we can select two points representing dark and bright soil, \(P_1=(X_1,Y_1)\) and \(P_2=(X_2,Y_2)\), as illustrated below.

These two points can be used to derive:

Slope of the soil line:

\[ a = \frac{Y_2-Y_1}{X_2-X_1} \]

Intercept of the soil line:

\[ b = Y_1-aX_1 \]

Once the soil line has been defined, the PVI can be calculated as:

\[ PVI = \frac{\rho_{\mathrm{NIR}}-a\rho_{\mathrm{RED}}-b}{\sqrt{1+a^2}} \]

where \(\rho_{\mathrm{NIR}}\) and \(\rho_{\mathrm{RED}}\) represent reflectance in the near-infrared and red bands, respectively.

The soil line itself has a PVI of zero. With this sign convention, pixels above the soil line have positive PVI values.

Derivation of the soil line

Define the soil line for your Sentinel-2 image by selecting two points representing dark and bright soil in the red–NIR feature space. Use these points to calculate the slope and intercept of the soil line and finally derive the PVI for your image.
