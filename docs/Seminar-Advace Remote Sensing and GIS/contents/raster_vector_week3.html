This week

This week we will get basic knowledge how to work with vector data in R and how to intersect vector and raster data. You will work with three datasets: * You already know the elevation data. * Additionally you will work with a polygon dataset showing the municipalities in this area. * Moreover, you are going to work with a table that consists of meteorological data in the study area. You will learn how to create a point vector layer from this table.

You will learn how to work with vector data, e.g. how to have a look at the attribute table and how to select specific vector data. Moreover, you will see how to extract information from a raster layer for the vector data.

We will also have a look how “loops” can be implemented and you will try to create a loop yourself.

  • Just for fun: Two further functions to visualize raster data such as DEMs. Use the functions levelplot() and plot3D() from the package rasterVIS. You will also need to install the raster package. With plot3D() a new window opens showing a 3D perspective of the DEM. You may change the view, zoom level etc. by using your mouse wheel. Unfortunately, plot3D() only works with a RasterLayer object (format of raster layers with the library (raster()) and not with a SpatRaster object as used with the terra library. Therefore we need to change the data type using the function raster()

# Convert raster from "SpatRaster" (the terra format) to "RasterLayer" (the raster format; the package raster will not be maintained in # the future)
DEM.raster <- raster(DEM)
plot3D(DEM.raster)

The geographic extent of the data do not match. Create a geographic subset of the polygon data that matches the DEM using crop(). We used this function also last week. This week it is even easier as we can simply use the extent of another spatial dataset (here the DEM) to which the polygon data are clipped.

2. Intersection of Raster and Vector Data (Loop)

Usually, using functions such as lapply() is very efficient and is preferred over implementing loops. But because of the enormous amount of pixels it might be difficult to detect mean heights for all municipalities using the functions extract() and lapply() due to the computer`s specifications (limited working memory).

Therefore, alternatively to the exercise, we will implement a loop that is not very elegant but works.

That it is how a for loop looks like in R.

# Create a vector with a sequence from 1 to 20 with stepsize 2.
input <- seq(1,20, 2)

print("This loop calculates the square of the 10 elements of the vector input")

# Initialize vec. There are several ways to initialize vectors. This is one...
vec <- vector(length=length(input))

for(i in 1:length(input)) {
  # i-th element of `input` squared into `i-th position of `vec`
  vec[i] <- input[i]*input[i]
  print(paste0("Loop ", i,": the square of ", input[i], " is ", vec[i]))
}

print(vec)
