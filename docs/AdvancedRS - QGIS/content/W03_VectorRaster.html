1. Open and Visualise Raster Data

Adding a raster layer in QGIS:
  • Open QGIS.
  • Click Layer (top menu).
  • Select Add Layer → Add Raster Layer
  • Click Browse.
  • Navigate to your raster file (e.g., .tif, .img, .asc).
  • Select the file.
  • Click Open.
  • Click Add.
Plot Raster:
  • Select Raster Properties
  • Symbology
  • Render Type: Single Band Pseudo Color
  • Select required color ramp for plotting DEM
  • What color ramp is best for Plotting the DEM?

Just for fun: Visualize your DEM in 3D:
  • Go to View option
  • Select 3D Map View > New 3D Map
  • Click on the setting icon
  • Select DEM as the Terrain
  • Optionally, Hillshade can be added for better shading
  • Hold the shift key and toggle with mouse for a fully interactive 3D Map
  • How are the results affected when changing the vertical scale of the 3D Map?

2. Create a point vector dataset by importing a table

Open the file stations_bawue_montly_temp.csv:
  • Layer > Add Layer > Add Delimited Text Layer
  • Select stations_bawue_montly_temp.csv
  • In File Format > Select Custom Delimiters > Tick Semicolon
  • In Geometry Definitions > Select Point Co-ordinates
  • X Field = Lon - Y Field = Lat
  • Click Add
View the Data Table
  • Right click on csv file
  • Open attribute table
Access Longitude and Latitude of a specific station:
  • Open Attribute Table of the csv file added
  • Select by Expression (ε icon)
  • Type “Station” = 257
  • Click Select
  • The station will be shown on the map

Plot Station Locations and convert in vector points:
  • Select Processing > Toolbox > Create Points Layers from Table
  • Input your csv file
  • Select X field = Lon - Y field = Lat
  • All station locations are plotted in vector format
  • Export the newly formed vector data in ‘ESRI Shapefile’ format
  • Is the newly formed vector point file visible on QGIS? If not, explain why?
    Hint: Check Longitude and Latitude <!–
  • Fix lattitude and longitude by going in the field calculator for the excel data added and using the expression: to_real(replace(“latitude”, ‘,’, ‘.’))
  • This converts the , into . for creating vector points from csv –>
Plot the final raster with vector points:
  • Vector point layer must be above the raster layer
  • Change can be made to both the raster data and vector point data in properties by editing colour, contrast and hue through symbology

4. Projections, transformations and subsetting

Convert Raster to binary mask layer:
  • Raster > Raster Calculator
  • Enter Expression (“YOUR_DEM” >= 0)
  • What does this do? Explain your results.
Polygonize the Raster:
  • Raster > Conversion > Polygonize (Raster to Vector)
  • Select the newly created boundary DEM file
  • Click Run
Clip polygons into the DEM boundary:
  • Vector > Geoprocessing Tools > Clip
  • Input Layer = District Boundary
  • Overlay Layer = Raster boundary polygon (VECTORIZED)
  • Click Run

5. Intersection of Raster Layers and Vector Data

Calculate the mean height of each municipality where a meteorological station is present within the DEM:
  • Open Geoprocessing Toolbox > Raster Analysis > Zonal Statistics
  • Input Layer = Clipped Municipality Polygons
  • Raster Layer = DEM
  • Statistics to Calculate = Mean (You can also add min, max, median etc for further analysis)
  • Add a Output column prefix (Eg: DEM_)
  • Run
  • A new Vector file is produced with an added column, which shows the mean height for each meteorological station

Plot a diagram:
  • Open properties for the new vector file with mean height data > Diagrams
  • Select Histogram of bar chart
  • Value = DEM_mean
  • Mean height diagram plotted on the polygon.
  • Hint: Alternatively you can also use the Data Plotly plugin in QGIS for better Plots.

Plot a map with all polygons lower than 700 m a.s.l displayed as black polygons, all the other polygons in red colour:
  • Open symbology for vector layer containing calculated mean height
  • At the top dropdown select Rule-Based
  • Add a new rule
  • Label = < 700m
  • Filter expression: “DEM_mean” < 700
  • Set fill colour to black
  • Repeat the process for heights above 700m.
  • What would the Filter Expression be for heights above 700m?
